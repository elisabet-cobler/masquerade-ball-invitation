# Invitación Baile de Máscaras

Invitación web interactiva diseñada para un evento de baile de máscaras (contenido en catalán). Desarrollada como una página web ligera y adaptable, con estilos personalizados y animaciones.

## Demostración en vivo

Puedes ver la página funcionando aquí: `https://elisabet-cobler.github.io/masquerade-ball-invitation/`

## Características

* **Detalles del evento:** Presentación clara de los horarios, ubicación y código de vestimenta.
* **Diseño adaptable (Responsive):** Optimizada tanto para dispositivos móviles como para ordenadores.
* **Estilo personalizado:** Estética visual diseñada a medida para la temática de baile de máscaras.

## Tecnologías utilizadas

* **HTML5**
* **CSS3**

## Cómo ejecutarlo en local

1. Descarga o clona los archivos de este repositorio.
2. Abre el archivo `index.html` directamente en cualquier navegador web moderno.
